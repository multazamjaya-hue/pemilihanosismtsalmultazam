PANDUAN INSTALASI LENGKAP — APLIKASI PEMILIHAN OSIS
=====================================================

Aplikasi terdiri dari 3 bagian:
- Frontend  : index.html  (di-host di luar Apps Script, contoh: GitHub Pages)
- Backend   : code.gs     (dijalankan di Google Apps Script)
- Database  : Google Sheet (otomatis dibuat bila belum ada)

Login awal setelah instalasi:
  Username : admin
  Password : admin123
  => SEGERA ganti password setelah masuk pertama kali.


--------------------------------------------------------------
LANGKAH 1 — SIAPKAN PROJECT APPS SCRIPT + GOOGLE SHEET
--------------------------------------------------------------
1. Buka https://sheets.new di browser (pakai akun Google yang akan
   menjadi pemilik aplikasi).
2. Beri nama spreadsheet, misalnya "Pemilihan OSIS Database".
3. Di spreadsheet, klik menu Extensions (Ekstensi) > Apps Script.
   Editor project Apps Script akan terbuka dan otomatis terhubung
   ke spreadsheet aktif.
4. Hapus semua kode bawaan di editor, lalu tempel SELURUH isi
   file code.gs dari aplikasi ini.
5. Simpan (Ctrl+S) dan beri nama project, misalnya
   "Pemilihan OSIS Backend".


--------------------------------------------------------------
LANGKAH 2 — MEMBUAT DATABASE (SEKALI SAJA)
--------------------------------------------------------------
Jalankan fungsi CreateDatabase dengan salah satu cara:

  Cara A (dari editor Apps Script):
  - Pada toolbar editor, pilih "CreateDatabase" pada dropdown
    fungsi, lalu klik "Run". Izinkan akses (authorization) bila
    diminta.

  Cara B (dari spreadsheet):
  - Buka kembali spreadsheet, lalu klik menu yang muncul:
    "Pemilihan OSIS > Buat Database".

Yang dilakukan CreateDatabase:
  - Membuat sheet: Admin, Kelas, Pemilih, Paslon, Pengaturan,
    Vote, Log, lengkap dengan header kolomnya.
  - Mengisi pengaturan default (nama sekolah, logo, folder Drive,
    waktu mulai/tutup).
  - Membuat akun admin pertama: admin / admin123.
  - Memformat kolom Token sebagai teks, supaya token dengan angka 0
    di depan (misalnya 012345) tidak terpotong jadi 5 digit.

Fungsi ini aman dijalankan berulang kali — sheet yang sudah ada
tidak akan terhapus.


--------------------------------------------------------------
LANGKAH 3 — DEPLOY SEBAGAI WEB APP
--------------------------------------------------------------
1. Di editor Apps Script, klik "Deploy" > "New deployment".
2. Klik ikon gerigi (setelan) > pilih tipe deployment "Web app".
3. Isi "Description", misalnya "Versi produksi".
4. "Execute as" = "Me" (akun Anda) — alias pemilik.
5. "Who has access" = "Anyone" (siapa saja).

   PENTING: harus "Anyone". Jika tidak, siswa tidak akan bisa
   memanggil API dari halaman web di luar.

6. Klik "Deploy". Izinkan akses saat diminta, lalu salin URL
   Web App yang tampil, bentuknya:
     https://script.google.com/macros/s/xxxxxxxx__/exec
7. Simpan URL tersebut baik-baik sebagai "URL Web App".

CATATAN:
- Setiap kali code.gs diubah, perubahan baru berlaku setelah Anda
  membuat deployment baru / versi baru (Deploy > Manage deployments
  > Edit > New version), karena Apps Script memakai snapshot versi.
- URL Web App tidak berubah selama versi aktif masih sama.


--------------------------------------------------------------
LANGKAH 4 — MENGHUBUNGKAN FRONTEND KE BACKEND
--------------------------------------------------------------
Buka file index.html dari aplikasi ini. Cari baris ini
(sekitar baris 530):

    const SCRIPT_URL = 'https://script.google.com/macros/s/GANTI_DENGAN_ID_WEB_APP_URL_ANDA/exec';

Ganti tulisan GANTI_DENGAN_ID_WEB_APP_URL_ANDA dengan ID URL Web App hasil
Langkah 3, lalu simpan files.

Contoh setelah diubah:

    const SCRIPT_URL = 'https://script.google.com/macros/s/AbC123.../exec';


--------------------------------------------------------------
LANGKAH 5 — HOST FRONTEND DI GITHUB PAGES (CONTOH)
--------------------------------------------------------------
1. Buat repository (repo) publik baru di GitHub,
   misalnya: pemilihan-osis.
2. Upload file index.html ke folder paling atas (root) repo.
   Nama file HARUS index.html agar otomatis menjadi halaman utama.
3. Buka repo > menu Settings > menu "Pages".
4. Bagian "Build and deployment":
   - Source = "Deploy from a branch"
   - Branch = main (atau master) dan folder = "/ (root)"
   - Klik Save.
5. Tunggu beberapa saat sampai situs dinyatakan aktif.
6. Aplikasi siap diakses di URL:
     https://<username>.github.io/pemilihan-osis/
   Bisa juga di-host di penyedia hosting statis lain (Netlify,
   Vercel, Cloudflare Pages, dsb.) — cukup upload index.html.

Catatan:
- Tidak ada proses build, karena aplikasi semuanya berbentuk satu
  file statis.
- Untuk dipakai dari HP, tambahkan URL ke bookmark agar mudah dibuka.


--------------------------------------------------------------
LANGKAH 6 — KONFIGURASI AWAL
--------------------------------------------------------------
1. Buka URL frontend Anda (https://<user>.github.io/pemilihan-osis/).
2. Login dengan username "admin" / password "admin123".
3. Segera ganti password lewat menu Profil (klik info pengguna di
   kanan atas > Profil).
4. Buka menu Pengaturan, lalu isi:
   - Nama Sekolah           : nama sekolah Anda.
   - URL Logo Sekolah       : URL / ID file foto logo (mis. logo.png).
   - ID Folder Google Drive : folder tempat semua foto paslon
     disimpan. Cara ambil ID: buka folder di Drive, lihat URL
     browser, ambil bagian setelah "folders/".
   - Waktu Mulai & Waktu Tutup Pemilihan : tanggal + jam jadwal.
   Jika ID Folder belum diisi, saat upload foto muncul pesan
   "ID Folder belum diisi oleh Admin" — isi dulu folder tersebut.
5. Siapkan data melalui menu Data Master:
   - Kelas : tambahkan semua kelas. Isi dahulu karena detaknya
     dipakai oleh data pemilih.
   - Admin & Panitia : buatkan akun bagi panitia (Peran: Panitia).
   - Pemilih : isi nama, jenis kelamin, dan kelas. Token 6 digit
     di-generate otomatis (bisa dibuat ulang). Bisa juga impor
     massal melalui file CSV.
   - Paslon : nomor urut, ketua, wakil, visi misi, upload foto
     foto ketua & wakil (format jpg/png/jpeg, maksimal 5 MB).


--------------------------------------------------------------
LANGKAH 7 — UJI COBA DAN SIAP DIPAKAI
--------------------------------------------------------------
1. Sebelum waktu pemilihan: login dengan token salah satu pemilih,
   pastikan muncul pesan "vote belum dibuka" + rentang jadwal.
2. Setelah waktu mulai: login token -> buka menu Pemilihan -> pilih
   seorang paslon -> klik Pilih -> konfirmasi -> riwayat tampil.
   Coba pilih lagi, harusnya ditolak ("Anda sudah melakukan vote").
3. Login panitia -> buka Monitor: dashboard real-time, auto-refresh
   10 detik, fullscreen, dan breakdown per kelas.
4. Login panitia -> menu Hasil -> cetak laporan rekap
   (tombol Print di halaman laporan).
5. Cek log aktivitas di Dasbor (siapa mengubah apa kapan).

Jika semua lolos, aplikasi SIAP untuk pemilihan sesungguhnya.
